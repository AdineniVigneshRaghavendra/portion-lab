# Potion Lab 🧪

Potion Lab is a small browser game where you mix ingredients to create potions. The lab gives you an order, and your job is to figure out the correct combination.

I built this project to experiment with JavaScript and Canvas and to learn how to make a simple game from scratch.

## How to Play

- You have three ingredients: Flame, Frost, and Toxic.
- Each round gives you a potion to make.
- Select two ingredients and click **BREW POTION**.
- Choose the correct combination to earn a point.
- Choosing the wrong combination costs you a point.
- Click **RESET** to clear your selection and move to the next order.
- Complete five correct orders to finish the lab.

## Built With

- HTML
- CSS
- JavaScript
- HTML Canvas

## Running the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `src/index.html` using Live Server, or open it directly in a browser.
4. Start mixing potions!



While building Potion Lab, I worked with Canvas drawing, click events, arrays, conditional logic, score tracking, and updating the game screen based on player actions.

It started as a basic screen with a few coloured bottles, and I gradually added ingredient selection, potion orders, scoring, and reset functionality.
