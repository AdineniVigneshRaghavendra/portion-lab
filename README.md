Potion Lab

Potion Lab is a small browser game where you mix ingredients to create potions. The lab gives you an order, and your job is to figure out the correct combination.

How to Play:

you have three ingredients: Flame, Frost, and Toxic.Each round gives you a potion to make.Select two ingredients and click "BREW POTION".Choose the correct combination to earn a point.Choosing the wrong combination costs you a point.Click "RESET" to clear your selection and move to the next order.Complete five correct orders to finish the lab.

 Built With:

- HTML
- CSS
- JavaScript
- HTML Canvas


Building:
```
npm.install
node build.mjs
```
